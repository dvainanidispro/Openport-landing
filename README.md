# OpenPort landing page

Ενιαία στατική σελίδα παρουσίασης του OpenPort για ελληνικούς δημόσιους φορείς.

## Χρήση

Άνοιξε το `index.html` σε browser ή χρησιμοποίησε τον τοπικό server του editor σου. Δεν χρειάζεται εγκατάσταση εξαρτήσεων ή build. Το Bootstrap φορτώνεται από CDN· η βασική διάταξη και το θέμα ορίζονται και στο τοπικό stylesheet.

## Αρχεία

- `index.html`: περιεχόμενο, ενότητες και πλοήγηση.
- `resources/style.css`: dark θέμα και responsive διάταξη, με την παλέτα της εφαρμογής OpenPort.
- `resources/script.js`: μενού κινητών και έτος copyright.
- `resources/logo.svg`, `resources/icon.svg`: τα υπάρχοντα branding assets της εφαρμογής.

Τα τοπικά paths είναι σχετικά, ώστε η σελίδα να μπορεί να φιλοξενηθεί και κάτω από repository path στο GitHub Pages. Όλα τα κουμπιά επικοινωνίας οδηγούν στη σελίδα επικοινωνίας της Computer Studio.

Το περιεχόμενο βασίζεται στο εγκεκριμένο προσχέδιο του OpenPort και παρουσιάζει τις προγραμματισμένες λειτουργίες ως διαθέσιμες, σύμφωνα με την οδηγία για το marketing κείμενο. Το διάγραμμα της αρχικής ενότητας παρουσιάζει τη ροή δημοσίευσης, δεν είναι στιγμιότυπο της εφαρμογής.

Δεν εκτελέστηκαν αυτόματοι, λειτουργικοί ή οπτικοί έλεγχοι, σύμφωνα με τις οδηγίες συνεργασίας. Δεν έχει γίνει δημοσίευση ή deployment.
